# Tokyo

Aplicação full-stack para gerenciamento de usuários e endereços, com frontend Angular e API Spring Boot usando PostgreSQL.

## Projetos

- [Frontend Angular](frontend/tokyo-front/README.md) — instalação, execução, funcionalidades e capturas de tela.
- [Backend Spring Boot](backend/desafio/README.md) — banco local, execução da API, configuração e documentação dos endpoints.

## Execução local

1. Siga as instruções do [README do backend](backend/desafio/README.md) para iniciar o PostgreSQL e a API.
2. Siga as instruções do [README do frontend](frontend/tokyo-front/README.md) para instalar as dependências e iniciar a aplicação web.
